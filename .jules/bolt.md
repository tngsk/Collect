## 2024-05-24 - Avoiding Synchronous Disk I/O in Async Handlers
**Learning:** In `update_screen`, using `pd.read_json(DATA_FILE)` synchronously reads from disk. This is a severe anti-pattern in FastAPI applications because synchronous disk reads will block the asyncio event loop, causing the entire API and all WebSockets to pause while Pandas parses the JSON file line by line. Furthermore, instantiating a large DataFrame to just filter a subset and perform a `value_counts()` was far too heavy for a real-time event.
**Action:** Always avoid `pd.read_json` (or any synchronous I/O) directly inside `async def` route/websocket handlers. Instead, cache the state in memory, append to it incrementally, and use native python collections (like `collections.Counter`) for small scale aggregations.
